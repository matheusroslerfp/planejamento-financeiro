# Planejamento Financeiro

Protótipo de uma nova ferramenta de planejamento financeiro para assessores/planejadores, como alternativa ao fluxo atual no Salesforce.

## Escopo do protótipo

- Cadastro do cliente (perfil, renda, despesas, patrimônio, família)
- Objetivos e metas (aposentadoria, imóvel, educação etc.)
- Projeções e simulações de evolução patrimonial
- Relatório do plano para o cliente

O protótipo é uma aplicação web navegável com dados fictícios, sem integração com sistemas reais.
