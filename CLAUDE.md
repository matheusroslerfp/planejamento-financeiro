# Contexto do projeto

Protótipo de uma nova ferramenta de planejamento financeiro. Hoje esse processo fica todo dentro do Salesforce; o objetivo é validar uma alternativa.

- **Usuários:** assessores/planejadores financeiros.
- **Escopo do protótipo:** cadastro do cliente, objetivos e metas, projeções/simulações e relatório do plano.
- **Tipo:** protótipo web navegável com dados fictícios, sem banco de dados nem integrações reais.
- **Stack:** HTML, CSS e JavaScript puros, abrindo direto no navegador. A máquina não tem Node.js nem Python, e o winget está bloqueado por política corporativa, então não dependa de ferramentas de build.
- **Referências:** o usuário vai enviar material do processo atual no Salesforce (prints, campos, planilhas, fluxos). Pergunte o caminho da pasta se ainda não estiver no repositório (sugestão: `referencias/`).
- **Próximo passo:** começar pelo fluxo de cadastro do cliente.

O usuário fala português; responda em português.
